# Evidence examples

One sample answer per checklist group, written the way a vendor would answer a buyer's questionnaire, with a redacted example record where a record is the evidence.

All examples use the same fictional setup so they can be read together:

> **Acme Support Agent v3.2** handles card-dispute chats for a mid-size bank. It can look up transactions and issue a provisional credit of up to $250 through the bank's card-servicing API. Larger credits go to a human queue.

Names, IDs and hashes are invented. Hash values are shortened with `…`. Adapt the shape, not the content: answer with what your system actually does.
